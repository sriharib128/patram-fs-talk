Before the practical questions, here is the whole design in one read, because you now know every piece.

A process starts with an address: the shard, the byte where the sample starts, and its length.

It tries the local file. Every process can work out the name by a fixed rule, so it does not have to ask anyone.

If the file is missing, it asks the daemon, shown as the dashed lines. The daemon downloads the shard once for the whole machine, the orange line, and warms it if it is an annotation shard.

Then the process reads the bytes directly from the drive, the thick green line. And every later read, for the rest of the run, is only steps 2 and 4. The daemon is asked once per shard, and the green line runs millions of times.
