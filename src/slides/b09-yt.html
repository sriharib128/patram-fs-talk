Before we move on, try this one. There are ten million small files in the object store. Each takes one request. And one request can bring back 300 bytes or 10 gibibytes, for the same cost.

How would you cut the number of requests? Option A: send them in parallel, as many at once as you can. Option B: pack the small files into large ones. Which would you pick?

B. Parallel requests are still ten million requests against the same limit. If one trip can carry anything, the answer is to fill the truck. That is the next part.
